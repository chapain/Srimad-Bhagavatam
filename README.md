# श्रीमद्भागवत महापुराण — नेपाली अध्ययन एप

श्रीमद्भागवत अध्ययनका लागि नेपालीमा बनेको हल्का, मोबाइलमैत्री वेब एप। यसमा बाह्र स्कन्धका ३३५ अध्यायको शीर्षक, विषयगत क्रम र पढाइ-प्रगति संरचना कायम छ।

## पुनर्लेखनको हालको अवस्था

**बाह्रै स्कन्धका परिचय तथा ३३५ अध्यायका सारांश र मुख्य-विन्दुका प्रारम्भिक नेपाली मस्यौदा तयार छन्।** यी सामग्री प्रमाणित अनुवाद वा अन्तिम संस्करण होइनन्। स्रोतसँग अध्याय-दर-अध्याय मिलान, कथ्य-समीक्षा र नेपाली सम्पादन बाँकी छ। समीक्षा गर्नका लागि `docs/content-review-manifest.json` मा प्रत्येक अध्यायको अवस्था, स्रोत-सन्दर्भ र समीक्षक विवरण राख्ने संरचना तयार छ; हाल कुनै अध्यायलाई स्रोत-सत्यापित वा सम्पादकीय स्वीकृत भनिएको छैन।

कथाक्रमका लागि सार्वजनिक-डोमेन अंग्रेजी अनुवादका Internet Archive OCR प्रतिलिपिहरू सहायक रूपमा मात्र हेरिएका छन् (चतुर्थदेखि नवम स्कन्धसम्मका मस्यौदामा): [Dutt अनुवाद](https://archive.org/stream/proseenglishtran12dutt/proseenglishtran12dutt_djvu.txt) र [अर्को OCR प्रतिलिपि](https://archive.org/download/in.ernet.dli.2015.272582/2015.272582.Shrimad-Bhagwatam_djvu.txt)। दुवै OCR अपूर्ण/त्रुटिपूर्ण हुन सक्छन्; chunk विभाजन अध्याय-सीमाको प्रमाण होइन र सम्पूर्ण शास्त्रीय पाठको स्वतन्त्र पुष्टि भएको छैन। स्क्यानसँग मिलान, शङ्कास्पद अंशको जाँच र स्वतन्त्र तथ्य-समीक्षा बाँकी छन्। त्यसैले सामग्री प्रारम्भिक अध्ययन-मस्यौदा हो, अन्तिम वा प्रमाणित अनुवाद होइन।

अध्याय शीर्षक, विषयगत समूह, अध्याय-क्रम र चयनित संस्कृत श्लोक-ब्लकहरू पुरानै संरचनाबाट कायम छन्; ती सबैको शास्त्रीय स्रोत वा अनुवाद यहाँ पुनःप्रमाणित गरिएको छैन। एपबाट पुराना पद्य-स्रोत URL, अध्याय-स्तरका बाह्य citation, र तिनको स्रोत-सूची हटाइएको छ।

## चलाउने तरिका

```sh
python3 -m http.server 8000 --directory .
```

त्यसपछि `http://localhost:8000` खोल्नुहोस्। कुनै build system आवश्यक छैन।

## PWA / अफलाइन प्रयोग

HTTPS मा (वा स्थानीय विकासमा `localhost`) एप स्थापना गर्न सकिन्छ। पहिलो पटक अनलाइन खोलिसकेपछि service worker ले पृष्ठ, शैली, स्क्रिप्ट, आइकन र स्कन्ध सामग्री क्यास गर्छ। पढाइको प्रगति ब्राउजरको स्थानीय भण्डारणमा रहन्छ।

## मुख्य फाइलहरू

- `index.html` — पृष्ठ र एप सामग्री
- `assets/app.js`, `assets/styles.css` — नेभिगेसन, खोजी, पाठ र डिजाइन
- `data/canto-01.js`–`data/canto-12.js` — स्कन्ध/अध्याय संरचना र पुनर्लेखन सामग्री
- `docs/rebuild-from-public-domain-source.md` — स्रोत-नीति र समीक्षा-स्थिति
- `docs/content-review-manifest.json` — प्रत्येक अध्यायको स्रोत-जाँच तथा सम्पादकीय स्वीकृतिको म्यानिफेस्ट
- `tests/smoke-content.js` — सामग्री संरचना, पुनर्लेखन स्थिति र पाठ-स्वच्छता जाँच
- `tests/smoke.js` — jsdom प्रयोग गरी मुख्य UI व्यवहार जाँच

## परीक्षण

```sh
node tests/smoke-content.js
npm install --prefix /tmp/sb-test jsdom
NODE_PATH=/tmp/sb-test/node_modules node tests/smoke.js
NODE_PATH=/tmp/sb-test/node_modules node tests/smoke-responsive.js
```

स्वचालित परीक्षणले संरचना र UI जाँच्छ; कथाको सम्पूर्णता वा व्याख्यात्मक शुद्धता आफैँ प्रमाणित गर्दैन।
