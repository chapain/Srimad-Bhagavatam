# श्रीमद्भागवत महापुराण — नेपाली अध्ययन एप

श्रीमद्भागवत (भागवत महापुराण) अध्ययनका लागि बनाइएको सरल, छिटो र सुन्दर वेब एप — **सम्पूर्ण नेपाली भाषामा**।

## विशेषताहरू

- **बाह्र स्कन्ध** — प्रत्येक स्कन्धको कार्ड र परिचय
- **विषयगत विभाजन** — हरेक स्कन्ध भित्र विषय (प्रकरण) अनुसार अध्यायहरूको समूह
- **विस्तृत अध्याय-सारांश** — प्रत्येक अध्यायको छोटो होइन, **विस्तृत नेपाली सारांश** + मुख्य विषयहरू + महत्त्वपूर्ण श्लोक (देवनागरी, भावार्थसहित)
- **गोलो खोजी** — कुनै पनि नाम/घटना/विषय सम्पूर्ण ग्रन्थभरि खोज्ने
- **प्रगति ट्र्याकिङ** — "पढिसकेँ ✓" लगाउने; ब्राउजरमा सुरक्षित
- **अक्षर आकार परिवर्तन**, मोबाइल-मैत्री डिजाइन, नेपाली अंक (१, २, ३…)
- कुनै build system चाहिँदैन — खाली HTML/CSS/JS, धेरै हल्का

## स्रोत-नीति

- अध्याय-विभाजन **गीताप्रेस (गोरखपुर) प्रचलित संस्करण** अनुरूप
- सारांशहरू मूल ग्रन्थको कथा र उपदेशमा आधारित, स्वयंलिखित नेपाली अध्ययन-सामग्री

## चलाउने तरिका

```
python3 -m http.server 8000 --directory .
```
वा कुनै पनि static server। ब्राउजरमा `http://localhost:8000` खोल्नुहोस्।

## फाइल संरचना

```
index.html            — मुख्य पृष्ठ
assets/styles.css     — डिजाइन
assets/app.js         — राउटर, खोजी, प्रगति-ट्र्याकिङ
data/canto-01.js      — प्रथम स्कन्ध (१९ अध्याय, पूर्ण)
data/canto-02.js      — द्वितीय स्कन्ध (१० अध्याय, पूर्ण)
data/canto-XX.js      — बाँकी स्कन्धहरू क्रमशः
tests/smoke.js        — jsdom आधारित स्वचालित स्मोक-टेस्ट
```

## स्थिति

| स्कन्ध | अध्याय | स्थिति |
|---|---|---|
| १ | १९ | ✅ पूर्ण (सारांश थप विस्तृत) |
| २ | १० | ✅ पूर्ण |
| ३–१२ | ३०६ | 🚧 क्रमशः थपिँदै |

द्वितीय स्कन्ध ४ विषयगत प्रकरणमा विभाजित छ — अन्तकालीन साधना, विश्वरूप-ध्यान र
भक्ति-निर्णय (१–३); सृष्टि-प्रश्न, तत्त्व-क्रम र विराट्का विभूति (४–६); लीलावतार-दर्शन
र परीक्षित्का प्रश्न (७–८); चतुःश्लोकी उपदेश, दश लक्षण र स्कन्ध-समापन (९–१०)।

## परीक्षण (Verification)

प्रथम र द्वितीय स्कन्ध `tests/smoke.js` (jsdom) बाट जाँचिएका छन् — १२ स्कन्ध-कार्ड,
प्रथम स्कन्धका ८ प्रकरण / १९ अध्याय / ६ श्लोक-ब्लक / ८३ मुख्य-विन्दु, द्वितीय स्कन्धका
४ प्रकरण / १० अध्याय / ६ श्लोक-ब्लक / ६२ मुख्य-विन्दु, दुवै स्कन्धका सबै अध्याय खुल्ने,
अध्याय-नेभिगेसन, खोजी (`<mark>` हाइलाइटसहित), प्रगति-ट्र्याकिङ (localStorage),
अक्षर-आकार, साइडबार, नेपाली अंक, अनुपलब्ध तृतीय स्कन्धको placeholder र अमान्य
अध्याय-मार्गको सहज fallback — सबै पास।

चलाउन : jsdom रिपोजिटरीबाहिर जडान गरी `NODE_PATH` दिनुहोस् —

```
npm install --prefix /tmp/sb-test jsdom
NODE_PATH=/tmp/sb-test/node_modules node tests/smoke.js
```

यस चरणमा ठिक पारिएका दुई त्रुटि :

1. **खोजी मार्ग (search route)** — `#/search?q=…` मा प्रश्न-शृङ्खला पथसँगै टुक्रिने भएकाले
   `parts[0] === 'search'` कहिल्यै मिल्दैनथ्यो र खोजीले गृहपृष्ठ देखाउँथ्यो। अब `?` अघि/पछि
   छुट्याइन्छ (deprecated `RegExp.$1` पनि हटाइयो)।
2. **स्कन्ध-ब्यानर** — `getCanto()` ले मेटाको अध्याय-**सङ्ख्या** लाई सामग्रीको अध्याय-**सूची**ले
   प्रतिस्थापन गर्दा ब्यानरमा `१९` को सट्टा `[object Object],[object Object],…` देखिन्थ्यो।
